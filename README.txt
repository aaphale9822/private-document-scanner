PrivateScan - install on your phone
1. Host this folder (free): drag it onto https://app.netlify.com/drop  (or use GitHub Pages / Cloudflare Pages).
2. Open the https:// link on your phone.
   iPhone (Safari): Share > Add to Home Screen.
   Android (Chrome): menu > Install app / Add to Home screen.
3. After the first load it works fully offline. Scans stay on the device.
